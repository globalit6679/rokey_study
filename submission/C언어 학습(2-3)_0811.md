# 1. C언어

### main 함수

```c
#include <stdio.h>
int main() {
	printf('hello world\n');
	return 0;
}
```

- `#include <stdio.h>`
    - Python의 import처럼 파일을 프로그램으로 불러옴
    - stdio: standard input output으로 표준 입출력
    - .h: header 파일
- `int main(){}`
    - int: return type
    - main(): main 함수 정의
- `printf();`
    - 출력 함수
- `return 0;`
    - 0을 반환 → 프로그램 정상 종료를 의미

### 주석처리

- `/* */`: 여러 줄 주석

### 기수법

- `10진법(0~9)`: 각 자릿수에 10의 거듭제곱을 곱하여 더함
    
    $$
    7253=7×10^3+2×10^2+5×10^1+3×10^0=7000+200+50+3
    $$
    
- `2진법(0, 1)`: 각 자릿수에 2의 거듭제곱을 곱하여 더함
    - 컴퓨터에서 0과 1 숫자 표현
    
    $$
    6=4+2=1×2^2+1×2^1+0×2^0=110_2
    $$
    
- `16진법(0~9, A~F)`: 각 자릿수에 16의 거듭제곱을 곱하여 더함
    
    $$
    16782=4×16^3+1×16^2+8×16^1+14×16^0=0x418E
    $$
    

### 메모리 단위

- `bit`: 0 or 1 → 1개의 이진수
- `byte`: 8bit → 문자 하나
- `word`: 컴퓨터의 architecture에 따라 다름 → CPU가 한 번에 처리하는 데이터 단위
    - 64bit 컴퓨터 → 워드 크기: 64bit(8byte)
    - 워드 크기에 따라 메모리 접근 속도, 명령어 처리 등에 영향
