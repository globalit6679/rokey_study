# 1. 변수

변수: 컴퓨터의 메모리인 RAM이라는 기억공간에 데이터를 저장할 때 RAM의 **주소공간 16진수 대신에 사용하는 이름**

⇒ 즉, **바뀔 수 있는 어떤 값을 보관하는 곳**

ex) mineral - 변수 → 이 변수는 0x12345678의 주소부터 0x1234567B 주소까지 가리키고 있기 때문에 주소공간 하나하나에 값을 넣을 필요 없음

![image.png](attachment:c7f86bc7-1714-43ca-903e-81a0610818a5:image.png)

- 변수명 정의 규칙
    - 숫자가 앞에 위치하면 안됨
    - 오직 영어, 숫자, _(언더바) 로만 구성
    - 띄어쓰기가 있으면 안됨
    - C 언어 예약어 사용 불가능
    - 대소문자 구분
- 변수 선언
    
    ```c
    #include <stdio.h>
    int main() {
      int a;
      a = 10;
      printf("a 의 값은 : %d \n", a);
      return 0;
    }
    ```
    
    - `int a;` → a라는 변수에 int형인 데이터를 넣겠다
    - `a = 10;` → a변수에 10이라는 값으로 초기화
- 데이터 type과 크기
    
    
    | **type** | 크기 | **범위** |
    | --- | --- | --- |
    | `char` | 1 byte | `unsigned char`: 0 - 255
    `signed char`: -128 - 127 |
    | `short` | 2byte | `unsigned short`: 0 - 65,535
    `signed shrort`: -32,768 - 32,767 |
    | `int` | 4byte | `unsigned int`: -2,147,483,648 - 2,147,483,647
    `signed int`: 0 - 4,294,967,295 |
    | `float` | 4byte |  |
    | `long` | 32bit: 4byte
    64bit: 8byte |  |
    | `long long` | 8byte |  |
    | `double` | 8byte |  |
- 데이터 서식 지정자
    
    
    | 서식 지정자 | 의미 | 출력 예시 |
    | --- | --- | --- |
    | `%d` | 10진수 정수 출력 | `65` |
    | `%o` | 8진수 정수 출력 | `ff` |
    | `%x`  | 16진수 정수 출력 (소문자) | `FF` |
    | `%X` | 16진수 정수 출력 (대문자) | `41` |
    | `%f` | 실수 출력 | `65.000000`  |
    | `%.숫자f` | 소수 (숫자)자리까지만 표시 | `.2f → 62.35` |
    | `%c` | 문자 출력 | `A` |
    | `%s` | 문자열 출력 | `"Hello"` |
    | `%u`  | unsigned 타입 |  |

수정된 코드

```c
#include <stdio.h>
int main() {
  int a;
  double b; // double형으로 선언

  a = 10;
  b = 3;
  printf("a / b 는 : %f \n", a / b);
  printf("b / a 는 : %f \n", b / a);
  return 0;
}
// 결과가 실수형으로 출력
```

double이 int보다 범위가 큰 자료형이므로, int형인 a가 double형으로 바뀜

그러므로 실수형으로 출력 가능

- 증감 연산자
    
    <aside>
    🔑
    
    1씩 증가시켜주는 연산자
    
    </aside>
    
    `전위형(prefix)`: 1을 먼저 더한 후 결과 반환 (++a)
    
    `후위형(postfix)`: 반환한 후 1을 더함 (a++)
    
    ```c
    #include <stdio.h>
    int main() {
      int a = 1;
    
      printf("++a : %d \n", ++a);
    
      a = 1;
      printf("a++ : %d \n", a++);
      printf("a : %d \n", a);
    
      return 0;
    }
    
    /*
    실행 결과
    ++a : 2 -> 1에서 1 증가 후 반환
    a++ : 1 -> 반환을 먼저(증가하기 전에 출력) 후에 a에 1을 더함
    a : 2 -> a에 1이 더해진 상황이므로 2 출력
    */
    ```
    
- 비트 연산자
    - AND: &
    - OR: |
    - XOR: ^
    - NOT: ~
    - SHIFT: >>. <<
- 논리 연산자
    - `&&`: AND
    - `||`: OR
    - `!`: NOT

# 3. 2의 보수 표현

컴퓨터는 2진수(0, 1)만 다루기 때문에 음수를 표현할 별도의 규칙이 필요

→ 양수를 기준으로 음수를 쉽게 계산할 수 있도록 한 방법

- 방법
    
    n bit 정수에서 -x를 표현
    
    1. x 를 b bit 2진수로 표현
    2. 모든 bit를 반전 → 1의 보수
    3. 반전시킨 bit에 1을 더함
    
    ex) -5 표현
    
    1. +5 → 0000 0101
    2. bit 반점 → 1111 1010
    3. +1 → 1111 1011
    
    ⇒ -5는 1111 1011
    
- 특징
    - MSB가 부호 비트 역할(0: 양수, 1: 음수)
    - 0은 부호없이 하나만 존재
    - 덧셈과 뺄셈은 같은 회로로 처리 가능하므로 HW가 단순해짐
    - unsigned 자료형의 경우, 음수로 해석될 수를 양수로 해석됨
- 오버플로우(overflow)
    
    자료형의 최대 범위보다 큰 수를 대입하면서 발생하는 문제
    
    - 양수 + 양수에서 음수 값이 나오거나, 음수 + 음수에서 양수 값이 나오는 경우
    - unsigned 자료형에서 0으로 나오는 등
